# Resultado de Vendas

Este e um exercicio da atividade de conversao de Portugol para JavaScript.

O programa pergunta as vendas de janeiro, fevereiro e marco. Depois soma os valores e mostra se a meta de R$ 17000 foi atingida.

## O que foi usado

- Variaveis para guardar as vendas e o total
- Entrada e saida de dados
- Vetor para guardar as tres vendas
- Laco for para somar as vendas
- Condicao if/else para verificar a meta

## Como rodar

Digite no terminal: node resultadoDeVendas.js

Depois informe as tres vendas que o programa pedir.

## Exemplo

Se as vendas forem 5000, 6000 e 7000, o total sera 18000. A meta foi atingida.
